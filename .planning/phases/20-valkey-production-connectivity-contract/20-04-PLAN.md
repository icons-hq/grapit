<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Operator workstation -> production API | Smoke auth and safe fixture IDs are used to call production booking endpoints. |
| Production API -> Valkey | Health, Lua, and Socket.IO checks traverse Cloud Run VPC/PSC into Memorystore. |
| Cloud Run scaling -> production availability/cost | Temporary multi-instance proof can alter service scaling and must be restored. |
| Production logs/Sentry -> planning artifacts | Runtime evidence must be summarized without secrets or private customer data. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-20-01 | Information Disclosure | Smoke script and UAT artifacts | mitigate | Script reads auth from `GRABIT_SMOKE_AUTH_HEADER_FILE`, records only command shape and sanitized results, and value-sensitive artifact grep bans full `redis://` values, bearer token values, cookie assignments, JWT-like tokens, real phone numbers, payment keys, order IDs, and private customer data. |
| T-20-02 | Tampering | Production Socket.IO pub/sub | mitigate | Smoke requires `VALKEY_MODE=cluster`, health metadata, and two-instance `seat-update` proof; failure blocks approval. |
| T-20-03 | Denial of Service | Live mode mismatch | mitigate | UAT compares `grabit-valkey` live `CLUSTER` mode with `VALKEY_MODE=cluster` and health/client metadata; mismatch is a failed smoke gate. |
| T-20-04 | Tampering | Lua key slot drift | mitigate | Production smoke exercises real lock/status/unlock path and log keyword scan for `CROSSSLOT`, `MOVED`, and `ASK`; Plan 20-03 supplies automated cluster coverage. |
| T-20-05 | Integrity | Real inventory mutation | mitigate | UAT requires operator-approved safe fixture, authenticated owner context, unlock success or TTL expiry proof, and no unauthenticated mutation endpoint. |
| T-20-06 | Denial of Service | Temporary scale not restored | mitigate | UAT records pre-state, temporary scale/traffic command, restore command, and checked `Scale restored` evidence before approval. |
</threat_model>
