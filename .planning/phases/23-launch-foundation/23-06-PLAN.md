## Trust Boundaries
| Boundary | Description |
|----------|-------------|
| email link -> auth API | Verification tokens prove email ownership and are replay targets. |
| refresh cookie -> session store | Refresh token families represent device sessions and theft handling. |
| phone input -> SMS provider | User input reaches Infobip and Valkey rate-limit keys. |

| Threat ID | Category | Component | Disposition | Mitigation Plan |

| T-23-03 | Repudiation | legal-sensitive email copy | accept | Legal lock is Plan 05; auth emails are transactional. |
| T-23-04 | Spoofing | email verification, refresh tokens | mitigate | Hashed latest-token-wins tokens, 30-minute expiry, consumed state, throttled resend, family cap, and family-wide reuse revoke. |

| T-23-06 | Information disclosure | auth/SMS logs | mitigate | Do not log raw verification tokens, OTPs, reset links, or phone PII beyond existing masked patterns. |
