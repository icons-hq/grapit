## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-26-11-01 | Information Disclosure | AdminCutoverService | mitigate | Return redacted metadata and evidence refs only; never raw secrets, cookies, payment keys, QR tokens, or PII. |
| T-26-11-02 | Elevation of Privilege | AdminCutoverController | mitigate | Use RolesGuard and AdminCapabilitiesGuard with audit.read for the read endpoint. |
| T-26-11-03 | Tampering | Gate state normalization | mitigate | Preserve exact states and convert invalid/missing ledger to BLOCKED/no-go. |
| T-26-11-04 | Repudiation | finalEnableAllowed | mitigate | Require approvalState, approver, monitoring, and rollback/close trigger before approved non-PASS can unblock. |
| T-26-11-05 | Denial of Service | runtime artifact path | mitigate | Package `/app/phase26/26-GATE-LEDGER.json`, set CUTOVER_GATE_LEDGER_PATH, and return no-go/BLOCKED instead of 500 when unavailable. |
</threat_model>
