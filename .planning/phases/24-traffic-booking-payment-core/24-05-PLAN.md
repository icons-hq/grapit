| Boundary | Description |
|----------|-------------|
| confirm page -> Toss widget/provider | User-selected payment method leaves the app here. |
| provider webhook -> payment persistence | External payment status enters durable state here. |
| pending payment -> queue/admission state | An in-flight payment can outlive the original queue active window here. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-24-15 | T/R | `payment-webhook.controller.ts` | mitigate | Persist provider event ids and make webhook handlers idempotent before returning 200, preventing duplicate async payment or cancel transitions (Task 1). |
| T-24-16 | T | `confirm/page.tsx`, `toss-payment-widget.tsx` | mitigate | Gate overseas flows behind an explicit disclaimer checkbox and correct provider-specific request shapes so users cannot bypass required consent or hit an invalid branch (Task 2). |

</threat_model>
