# Quick Task 260507-q2c: Two public event categories

## Goal

현재 장르 중심 catalog surface를 launch 방향에 맞춰 `아티스트·셀럽`과 `IP 팝업` 두 분류만 사용하도록 전환한다.

## Decisions

- Public/admin creation categories are limited to two values:
  - `artist_celebrity` — 아티스트·셀럽
  - `ip_popup` — IP 팝업
- Existing production enum values are kept as legacy database values. The migration only adds new enum values so existing rows and old reservations are not invalidated.
- Public navigation, home category shortcuts, search filters, mobile menu, mobile tab bar, and admin performance creation use only the two launch categories.

## Plan

1. Add shared category constants and an expand-only database migration for the two new enum values.
2. Rewire visible web/admin category surfaces and localized copy from 8 legacy genres to the two launch categories.
3. Update focused tests and seed/test fixtures so the new default category is `artist_celebrity`.
