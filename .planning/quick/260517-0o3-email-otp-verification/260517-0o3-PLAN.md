# Email OTP Verification

## Goal
Change email verification from magic-link click verification to a 6-digit numeric code flow.

## Scope
- Backend issues and verifies 6-digit email verification codes.
- Email template displays the code instead of a verification link.
- Frontend email verification screen shows a 6-digit code input and submit button.
- Signup, social signup completion, login redirect, resend, and booking verification gating keep working.
- Preserve token route compatibility only as a fallback for already-sent old links.

## Verification
- API auth/email unit tests.
- Web auth email verification tests.
- API and web typecheck.
- Browser smoke if local dev servers are available.
