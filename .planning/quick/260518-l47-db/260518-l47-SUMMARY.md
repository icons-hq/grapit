# Quick Task 260518-l47 Summary

## Goal

회원 탈퇴 기능을 만들고, 어드민 회원 관리에서 탈퇴 처리와 DB 완전 삭제 기능을 추가한다.

## Completed

- `users` account lifecycle columns and migration `0021_account_withdrawal.sql` added.
- Logged-in users can call `POST /api/v1/users/me/withdrawal` from MyPage after explicit confirmation.
- Withdrawal revokes active refresh tokens, nulls password login, clears admin capabilities, disables marketing consent, and blocks future login/refresh.
- Admin users with `security.manage` can call `POST /api/v1/admin/users/:id/withdrawal` with reason and confirmation.
- Admin users with `security.manage` can call `POST /api/v1/admin/users/:id/hard-delete` only for withdrawn users, with blocker details for reservations, admin audit logs, seat operation history, and booking operation audit logs.
- Admin user management UI now displays account lifecycle state and separate destructive controls for soft withdrawal and hard delete.
