# Quick Task 260507-r4s: Category filter chips cleanup

## Goal

`아티스트·셀럽` / `IP 팝업` 두 분류 체계로 전환된 catalog page에서 기존 공연 장르용 subcategory chip row를 제거한다.

## Decisions

- 기존 chip `요즘HOT`, `오리지널/내한`, `라이선스`, `창작`, `내한`은 현재 판매 분류와 맞지 않으므로 노출하지 않는다.

- 오래된 URL의 `?sub=` 값이 남아도 목록 API에 전달하지 않는다.

## Plan

1. Genre page에서 subcategory chip UI와 관련 query state를 제거한다.
2. Performance list hook에서 legacy `sub` query param을 API 요청/cache key에 포함하지 않도록 한다.
3. 사용하지 않는 five-locale subcategory copy를 제거한다.
4. Typecheck, focused tests, browser reproduction으로 검증한다.
