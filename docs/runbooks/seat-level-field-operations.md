# 좌석별 현장 검표 운영

전면 개편 적용 후 새 검표에 사용하는 절차다. 기준은 [ADR 0011](../adr/0011-consume-one-ticket-item-per-field-scan.md)이다. 과거 계정·회차 일괄 입장 결과는 그대로 보존한다.

1. 현장 계정으로 로그인하고 `/field/check-in`에서 실제 공연명·회차·KST 시각을 선택한다. 일반 고객 계정은 검표할 수 없다. 입장과 특전 지급은 별도 capability이며, custom 권한 계정은 `field.benefits.redeem` 부여 여부도 확인한다.
2. 휴대폰 카메라로 구매자의 QR 링크를 열거나 QR 내용을 대체 입력란에 붙여넣는다. 화면을 여는 것만으로 입장되지 않는다. 좌석·회차·유효 상태를 확인하고 `이 좌석 입장 처리`를 누른다.
3. 동행자는 자기 좌석 QR로 별도 처리한다. 같은 구매자의 다른 좌석은 자동 입장되지 않는다. 이미 입장한 경우 이전 시각을 보고 재입장·예외 절차는 책임자에게 연결한다. 취소/환불 대기·완료, 다른 회차와 위조/확인 불가를 구분한다.
4. 포스터·사인 카드 등 실물은 해당 권리를 확인하고 품목별 `사용 처리` 성공 후 한 번만 건넨다. 입장 성공은 특전 수령 성공이 아니다. 결과를 받지 못하면 실물을 다시 지급하지 말고 같은 요청으로 확인한다. 지급 시작 뒤 설정·실제 재배정·rollback은 잠기며 기존 사용 기록을 지우지 않는다.
5. 통신 단절 뒤 검수한 입장 요청은 이 기기의 동기화 대기에 남는다. 대기 수는 서버 확정 인원에 포함하지 않는다. 다른 QR을 확인하거나 화면을 다시 열어도 해당 직원·회차의 대기 목록을 확인한다. 서버 오류로 확정되지 않은 기록은 대기를 유지한다.
6. 연결 복구 후 `보류 스캔 동기화`를 실행한다. 같은 요청의 성공 영수증은 서버 확정으로, 다른 요청이 먼저 입장했거나 티켓이 취소된 경우는 충돌로 표시된다. 거절 기록을 임의로 성공 처리하지 않는다. 완료된 로컬 기록에서는 QR 원문을 제거하고 결과 참조를 유지한다.
7. 오프라인 실물 지급은 하지 않는다. 연결 복구 또는 책임자의 별도 예외 원장이 필요하다. [실물 인수·지급 대조](benefit-physical-handoff.md)에서 재고와 실제 수령을 확인한다.

실제 판매 전에는 서로 다른 휴대폰 2대, 카메라 실패, 실제 통신 단절/복구, 현장 인수 담당자·실물 재고·예외 처리 기록을 별도로 검증한다. 데스크톱 브라우저의 네트워크 재현이나 합성 QR 테스트로 실기기 gate를 통과 처리하지 않는다.
