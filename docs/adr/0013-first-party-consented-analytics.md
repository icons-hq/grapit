# 선택 동의 기반 자체 방문 분석

기존 가입·결제 정본을 관리자에서 직접 비교하고 수집 범위를 통제하기 위해 NestJS 모듈과 PostgreSQL로 자체 분석을 구축한다. GA4 Standard와 PostHog Cloud도 무료 구간과 성숙한 분석 기능이 있으므로 가격만으로 배제하지 않았다. 외부 전송·국외이전, 별도 계정·API quota, 관리자 통합에 대한 요구와 현재의 1인 modular monolith 운영 조건을 함께 고려했다. 비교와 공식 출처는 [조사 근거](../research/2026-11-11-first-party-analytics-evidence.md)에 기록한다.

## 결정과 용어

- **방문자**는 무작위 브라우저 식별자다. 실제 사람 수 또는 기기 간 중복 제거 회원 수가 아니다. **세션**은 30분 무활동으로 구분하며 새로운 UTM 유입도 새 세션으로 구분한다.
- **관측 전환**은 동의한 방문 세션과 기존 가입·결제 시각의 연결이다. **DB 실적**은 동의 여부와 무관한 기존 회원·결제·취소 집계다. 브라우저에 가입 완료·결제 완료·취소 사실을 생성하게 하지 않는다.
- 회원 연결은 인증된 JWT의 계정으로만 수행하고, 다른 계정에 붙은 세션을 재할당하지 않는다. 가입 시점이 관측된 세션 안에 있을 때만 가입 기여도를 만든다. 첫 관측 유입과 가입 직전 세션 유입을 고정하며, 이후 로그인으로 가입 캠페인을 덮어쓰지 않는다. 인과 효과·광고비·ROAS는 추정하지 않는다.
- `analytics.read`를 새로 만들지 않고 기존 회원 집계와 같은 `audit.read`를 재사용한다. 기존 admin/legacy superuser와 reviewer·approver·finance bundle은 읽을 수 있다. operator·scanner bundle에는 기본으로 열리지 않는다. 개별 회원 보기 권한은 그대로다. 수집 스위치는 `security.manage`만 변경한다.
- 원본 IP·세부 기기 fingerprint는 사용하지 않는다. UTM은 운영자가 지정한 비개인 캠페인 라벨만 허용한다. 회원 연결이 가능하므로 완전 익명으로 안내하지 않는다. 마케팅 수신 동의를 분석 동의로 재사용하지 않는다.

## 저장·운영 경계

분석은 별도 최대 1개 PostgreSQL 연결을 사용한다. 예매용 풀에 대기열을 만들지 않으며, 혼잡·1.5초 statement timeout·300ms 연결 timeout 때 수집을 버린다. 20개 이하/16KiB 이하 배치와 별도 네트워크 throttle로 제한한다. 추가 연결은 배포 연결 예산에 포함하며 기존 DB의 CPU·I/O까지 물리적으로 분리하는 것은 아니다. 실판매 트래픽 검증 전에는 수집 중지 상태를 유지한다.

서버 `ANALYTICS_ENABLED`와 공유 DB 스위치가 모두 true여야 수집한다. 두 기본값은 false다. 기존 feature-flags는 프로세스 환경을 읽는 방식으로 재배포 없는 전 인스턴스 전환을 제공하지 않아 DB 스위치를 추가했다. 매 배치가 스위치를 읽으므로 중단 이후 새 배치는 쓰지 않으며 이미 진행 중인 배치는 완료될 수 있다. 웹은 30초마다 설정을 갱신한다.

원본 이벤트·세션·가입 유입 연결은 90일, 식별자가 없는 일·시간 집계는 365일 보관한다. 기존 5분 주기의 bounded worker가 pg-boss job을 등록해 재집계·삭제하며, backfill은 제한된 구간으로 나눠 후속 job을 보낸다. Valkey는 5분 활성 방문자 TTL 집합에만 쓴다. 기간 UV는 원본 세션에서 중복을 제거하며 시간별 UV를 합쳐 기간 UV로 표시하지 않는다.

선택 동의 철회는 향후 중단뿐 아니라 해당 방문자의 기존 raw·세션·가입 연결 삭제를 요청한다. 삭제와 수집은 visitor별 advisory lock으로 직렬화한다. 지연 전송이 기록을 되살리지 않도록 UUID의 SHA256 철회 표시를 최대 90일 유지하고 집계를 재작성한다. 네트워크 실패 시 삭제 요청만 재시도하며 서버 확인 전에 완료로 표시하지 않는다.

## 활성화 전 남는 결정

실제 ko/en 정책의 시행일·사전 공지·동의 버전은 책임자/법무 확인 후 기존 [문서 버전 절차](../runbooks/consent-document-versions.md)로 별도 반영한다. 이번 PR은 [개정 초안](../legal/analytics-privacy-amendment-draft.md)만 만들고 적용 정책을 바꾸지 않는다. 외부 광고 픽셀·히트맵·세션 리플레이는 보류한다. 트래픽과 유지보수 부담이 자체 구축 범위를 넘으면 외부 도구를 다시 평가한다.
