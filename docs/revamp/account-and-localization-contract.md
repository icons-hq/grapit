# 계정·인증·해외 이용 계약

2026-09-21 사용자 자율 위임에 따른 선택이다. 현행 Buyer Account, Verified Buyer Identity, Social Login Link, Reservation Owner의 구분을 보존한다. 코드 기준은 개편 시작 commit `9a6ca20a8a19ac302b69bf459cc64605cb5dd961`이다.

## 선택과 이유

- 탐색·공연 상세·지원은 비로그인으로 사용한다. 좌석을 잠그기 전에 일반 구매자의 기존 이메일·전화 인증을 확인한다. scarce seat 남용 방지와 기존 계정 보호를 위해 인증 요건을 이번 UI 개편에서 임의 제거하지 않는다.
- 가입 화면은 진행 상태와 필수/선택 동의를 분리한다. 입력, 검증, 오류, 재전송 뒤에도 선택 언어와 검증된 같은 사이트의 복귀 경로를 유지한다. 가입·이메일 확인 완료 후 바로 원래 공연 예매로 돌아간다.
- `returnTo`는 같은 사이트의 허용 상대 경로만 사용한다. 외부 URL·프로토콜 상대 경로·인증 페이지 순환은 거부한다. 인증 토큰·비밀번호·OTP·QR을 복귀 경로나 영속 브라우저 저장소에 넣지 않는다.
- 소셜 로그인은 기존 계정을 여는 수단이다. 공급자의 같은 이메일만으로 서로 다른 Buyer Account를 자동 합치지 않는다. 충돌은 기존 복구 절차로 안내하고 운영자 수동 병합은 기존 증거·감사 절차를 유지한다.
- 마케팅 동의는 예매 필수 요건과 분리한다. 동의 버전·시각·철회 이력을 보존하며 이미 산 티켓의 접근권을 동의 철회와 연동해 없애지 않는다.
- 프로필 이름·언어·마케팅 변경은 현재 예약 소유자를 바꾸지 않는다. 휴대폰 변경이나 계정 연결은 기존 재인증 기준을 따른다. 단순 표시 이름과 검증된 본인 식별값을 혼동하지 않는다.
- 탈퇴는 기존 제한과 보존 절차를 유지한다. 유효 예매/환불/권리 처리 없이 계정을 영구 삭제하는 경로를 새로 만들지 않는다.

## 언어·국가·시간·통화

| 값 | 의미와 규칙 |
| --- | --- |
| UI 언어 | 현행 `ko`, `en`, `th`, `zh-CN`. URL이 선택 언어의 기준이며 계정 선호는 기본값이다. 메뉴·설정 탭·가입·복귀·예매·티켓·지원에서 유지한다 |
| 계정 국가 | 구매자가 선택한 국가. 공급자에게 필요한 국가와 일치 여부를 검증하며 영어라는 이유로 US로 바꾸지 않는다 |
| 공연 기준 시간 | 공연장 시간대의 일시와 시간대를 표시한다. 현재 공연은 KST를 기본으로 하되 원 데이터는 UTC를 보존한다 |
| 구매자 현지 시간 | 필요한 화면의 보조 정보. 공연장 일시와 혼동하지 않도록 별도 표시한다 |
| 주문 금액 | 현재 상품·수수료의 KRW 금액. 원결제 이력의 정의를 유지한다 |
| 실제 PG 청구 | 서버가 확정한 통화·금액·견적 시점. KRW 상품 가격과 별도이며 결제 확정 전에 표시한다 |

정적 UI 문구는 공통 번역 계약에서 관리하고 서버 오류는 안정된 code를 언어별 복구 안내로 변환한다. 원문 계약의 의미·수수료·기한을 번역 과정에서 바꾸지 않는다. 번역 미검수 콘텐츠는 검수 상태를 운영자에게 알리고 임의의 번역 완료 표시를 하지 않는다.

## 정상·실패 검증

1. 해외 비로그인 구매자가 공연에서 가입으로 이동하고, 이메일 확인을 마친 뒤 같은 공연과 같은 언어로 돌아간다.
2. 재전송·OTP 오답·메일 링크 만료·네트워크 실패에서도 입력을 최소한으로 유지하고 다음 행동을 제공한다.
3. 로그인/가입 중 다른 계정으로 전환해도 기존 구매자의 예매·QR은 볼 수 없다.
4. 계정 설정 탭을 바꾸거나 새로고침해도 언어가 유지된다. createdAt이 있는 정상 계정의 가입일을 알 수 없다고 표시하지 않는다.
5. 세션 만료 후 인증을 복구할 때 이미 완료된 결제를 새 결제로 만들지 않는다. 주문 상태 확인으로 돌아간다.
6. 소셜 충돌, 비밀번호 재설정, 탈퇴의 사용자 안내·서버 권한을 검증한다. 외부 OAuth/SMS/메일 도달·사용자 직접 인증은 기존 미완료 실행 목록에 남긴다.

완료 판정은 브라우저 언어 표시만으로 하지 않는다. API가 반환한 소유권·인증 상태·동의 저장과 실제 경로 복귀를 함께 확인한다. 법적 보존기간이나 환불률을 새로 정한 문서는 아니다. 기존 계약을 보존하는 제품·인증 흐름의 결정이다.
